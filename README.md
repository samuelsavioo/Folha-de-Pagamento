# Sistema de Folha de Pagamento

Um sistema simples desenvolvido em Java para gerenciar e calcular a folha de pagamento de diferentes tipos de colaboradores. Projeto criado para colocar em prática fundamentos da linguagem, lógica de programação e orientação a objetos.

## 🚀 Funcionalidades

* **Cadastro de Colaboradores:** Registro de funcionários com validação de dados (bloqueio de valores negativos).
* **Cálculo Automático de Salário:** * **Padrão:** Recebe apenas o salário base.
    * **Comissionado:** Salário base + percentual de comissão sobre vendas.
    * **Produção:** Salário base + valor por quantidade de peças produzidas.
* **Relatório de Folha:** Listagem completa dos colaboradores armazenados e seus salários finais.

## 💻 Tecnologias Utilizadas

* **Java** (Linguagem principal)
* **Estruturas de Controle:** `if/else`, `switch`, `while`, `do-while`
* **Coleções:** `ArrayList` para armazenamento em memória dinâmico
* **Entrada de Dados:** `Scanner` para interatividade via terminal

## ⚙️ Como Executar

1. Baixe ou clone os arquivos do projeto (`Colaborador.java` e `SistemaFolhaPagamento.java`).
2. Abra os arquivos na sua IDE de preferência (IntelliJ, Eclipse, VS Code) ou compile via terminal.
3. Execute a classe principal `SistemaFolhaPagamento` para abrir o menu interativo.
